3. Panel Chrome

Charts & Tables
Thin 1px border, subtle inner bevel (light top edge / dark bottom edge), small-caps amber label header. Used for every popup reference panel.

4. Buttons

Beveled gradient fill, not flat web buttons — hover brightens + amber border, active presses down 1px with an inset shadow.

5. Counter-on-Hex Treatment

idle
selected (amber ring)
wounded state

Faint always-on hex grid (per M2 sign-off). Counter scaled to sit comfortably inside the hex, matching original counter/hex ratio. Selection = amber ring, no fill change. Status (wound/KIA/prone) is baked into the counter art itself where the source provides it (e.g. `_wounded` variants) rather than a separate stacked overlay.
